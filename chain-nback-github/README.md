# Chain N-back — The Archive of the Dead Kings

A dark-fantasy reasoning game that combines **working memory** (N-back) with **deductive logic**.
One clue appears at a time. On each move you combine the new clue with the clue from **N moves ago**
and decide whether the two clues together **guarantee** a statement: **Yes** or **No**.

Plain static web app (HTML, CSS, JavaScript). No build step, no server code, no accounts.

## Training modes

| Mode | Clues look like |
|---|---|
| Grammatical reasoning | "F comes before H", "D is not followed by C", passive and negated forms |
| Syllogisms | "All G are K", "No G is K", "Some G are not K", "Only K are G" |
| Conditionals | "If G happens, K happens", "only if", "unless", "if and only if" |
| Disjunctions | "G happens or K happens" (inclusive "or") |
| Belief bias | Syllogisms with real words, where some valid conclusions sound false and some invalid ones sound true |
| Varied | Each block picks a type; at 2-back or more, types can be mixed in one block |

Each mode has its own adaptive level (N from 1 to 15). When you swear to something that is not
guaranteed, the report names the trap, for example *undistributed middle*, *affirming the consequent*
or *affirming a disjunct*.

## Also included

- **Duels in the Archive**: play the same block as one of eight simulated historical logicians.
  The opponents are simulated (fixed accuracy, pace and typical mistakes), and the game says so on screen.
  Duel honour is a separate Elo-style rating.
- **Archive Cards**: an adaptive version of the Wason selection task (which cards must you turn
  to test a rule?), with seven rule types.
- **Guided tutorial**, three lives per round, Free and Timed rankings, Stroop option, optional
  sound and background music, keyboard controls (← Yes, → No).

## Run it

Open the folder with any static web server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. The app can be installed as a PWA and works offline after the
first visit. Progress is stored only in the browser (`localStorage`).
